# Adult Income Classification

A CS412 Data Science project focused on predicting whether an individual earns more than $50K/year based on demographic and employment-related features.

## Project Objectives

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Hypothesis testing
- Machine Learning classification
- Model evaluation and comparison

## Models

- Decision Tree
- Logistic Regression

## Results

- Decision Tree Accuracy: 82.70%
- Logistic Regression Accuracy: 85.24%
